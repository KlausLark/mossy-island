# Roadmap

## Milestone 0 — First playable island (current)
- [x] Runtime tile world (64 × 48)
- [x] Separate terrain cells, not a flattened world background
- [x] Player movement, camera tracking and basic collisions
- [x] Click-to-walk path search
- [x] Independent world entities and basic ambient motion
- [x] Lumo dialogue and starter quest
- [x] Resource gathering and simple building placement
- [x] Tasks and focus timer
- [x] Local save
- [ ] Verify a complete play session in Chrome and Edge
- [ ] Verify Windows 10/11 launch from a clean folder

## Milestone 1 — A living world
- [ ] Cohesive original terrain and sprite sheets
- [ ] Directional idle/walk/interact animation sets
- [ ] NPC schedules, reactions and dialogue state
- [ ] Object-specific interaction animations and sound
- [ ] Weather, seasons and day/night lighting
- [ ] Hand-authored starting region with landmarks
- [ ] Robust pathfinding and collision masks

## Milestone 2 — ADHD-friendly focus experience
- [ ] One-tap 5-minute start and gentle re-entry after interruption
- [ ] Pause/resume without punishment
- [ ] One clear next action, optional planning
- [ ] Reduced motion, low-stimulation mode, adjustable UI and audio
- [ ] Keyboard remapping and full keyboard navigation
- [ ] No shame-based streak loss or punitive reminders
- [ ] Test with neurodivergent users; do not make medical efficacy claims

## Milestone 3 — Content
- [ ] Layered avatar customization
- [ ] New island regions and unlockable biomes
- [ ] Fishing, farming, crafting, cooking and collection
- [ ] More quests, NPCs, buildings and decorative objects
- [ ] Save export/import, backup rotation and version migration

## Milestone 4 — Desktop product
- [ ] Native Windows shell and installer
- [ ] Crash-safe saves and recovery UX
- [ ] Performance profiling on integrated GPUs
- [ ] Automated browser tests and Windows QA matrix
- [ ] Accessibility and privacy review

## Release gate
A milestone is complete only after interaction, persistence, accessibility and regression tests pass. A screenshot is not a test.
